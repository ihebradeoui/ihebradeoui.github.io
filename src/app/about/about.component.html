About CosmicWorlds

An interactive 3D solar system you can make your own

What is CosmicWorlds?

CosmicWorlds is a browser-based, real-time 3D planetary explorer powered by Babylon.js. Visitors can fly through beautifully rendered solar systems, claim and name planets, customise them with unique visual effects, and compete on the leaderboard for the longest-held planet name.

Everything happens live — planet names, descriptions and visual customisations are stored in a shared Firebase database, so every visitor sees the same universe in real time.

Features

  • 🌍 Interactive 3D Solar Systems — Explore multiple galaxies with realistically inclined orbits, a glowing sun, and planets of various shapes and sizes.
  • ✏️ Claim & Customise Planets — Register a free account, rent a planet with in-app credits, and personalise it with a name, description, and one of 20+ visual effects including rings, auras, moons, and particle effects.
  • 🏆 Leaderboard — The leaderboard tracks which planet names have been held the longest, rewarding dedicated explorers.
  • 🔥 Daily Streaks — Log in every day to build a streak and unlock extra customisation slots.
  • 🎵 Ambient Soundtrack — An immersive procedural music engine generates a unique space melody using the Web Audio API.
  • 📱 Responsive Design — Fully playable on desktop, tablet, and mobile browsers with touch support.

Technology Stack

  • Frontend: Angular 13, TypeScript, SCSS
  • 3D Engine: Babylon.js — WebGL-powered rendering
  • Backend & Auth: Google Firebase (Realtime Database + Authentication)
  • Hosting: GitHub Pages with automated CI/CD via GitHub Actions
  • Ads: Google AdSense

How to Play

  1. Visit the home page — the interactive solar system loads automatically.
  2. Drag to rotate the camera, scroll or pinch to zoom in and out.
  3. Click any planet to view its details. If it is unclaimed, you can claim it!
  4. Create a free account to earn credits by watching ads, then rent a planet to give it your own name and visual theme.
  5. Return daily to build your streak and unlock additional customisation slots.
  6. Check the leaderboard (🏆 button) to see who owns the most iconic planets.

Open Source

CosmicWorlds is open source. The full source code is available on GitHub. Bug reports and feature requests are welcome via the issue tracker.
